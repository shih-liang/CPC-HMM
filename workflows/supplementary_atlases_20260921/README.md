# Supplementary Fig. 1

Set `HCP_SOURCE_PACKAGE` to the bundle generated by `prepare_figure_sources.py`.
The renderer creates `source_data/` and copies its two inputs from the bundle.
When this variable is unset, provide `source_data/cpca_basis_REST1_LR.npz` and
`source_data/surfaces_and_eigenmodes.npz` directly. An explicitly configured bundle
takes precedence over previous local copies.

From the repository root:

```bash
python workflows/supplementary_atlases_20260921/code/make_figures.py
```

Use prepared inputs in a disposable copy. The retained helper modules support only this current figure or supplement layout; they are not separate figure entrypoints. See the [root README](../../README.md) and [input guide](../../docs/FIGURE_INPUTS.md).
